# مافيا المدينة — نسخة GitHub Pages

هذه نسخة ثابتة من اللعبة مناسبة للنشر على GitHub Pages. لا تحتاج إلى Node.js أو خادم خلفي؛ ملف `index.html` يحتوي على HTML وCSS وJavaScript الخاص باللعبة.

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع `index.html` و`README.md` إلى جذر المستودع.
3. افتح **Settings → Pages**.
4. تحت **Build and deployment** اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/(root)`، واضغط **Save**.
5. افتح رابط Pages الذي يظهر بعد اكتمال النشر.

## ملاحظات

- تقدم اللعبة يُحفظ محليًا في المتصفح باستخدام `localStorage`؛ لا تتم مزامنته بين الأجهزة أو المتصفحات.
- بعض صور التدريب والمباني تُحمّل من مواقع خارجية، لذا تحتاج إلى اتصال بالإنترنت وقد تتغير إذا أزالت تلك المواقع الصور.
